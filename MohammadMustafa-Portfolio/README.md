# Mohammad Mustafa Portfolio

React + Vite portfolio for Mohammad Mustafa, split into reusable components, data modules, CSS files, and animation helpers.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Structure

- `public/assets/` — public background and resume assets
- `src/components/` — page components and reusable cards
- `src/data/` — projects, skills, journey, and achievement data
- `src/styles/` — component-oriented CSS
- `src/animations/` — GSAP and interaction helpers
